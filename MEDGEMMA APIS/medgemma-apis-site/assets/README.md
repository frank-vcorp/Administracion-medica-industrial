# assets/

Directorio reservado para recursos estáticos del micrositio.

## Archivos sugeridos para agregar

| Archivo | Descripción |
|---------|-------------|
| `favicon.ico` | Ícono del sitio (32x32 o 64x64 px) |
| `og-image.png` | Imagen de previsualización para redes sociales (1200x630 px) |
| `logo.svg` | Logotipo de la empresa o servicio |
| Logos de clientes | Imágenes de clientes o referencias cuando estén disponibles |

## Para usar og-image

Agrega en `<head>` del `index.html`:
```html
<meta property="og:image" content="https://tu-dominio.com/assets/og-image.png" />
```

## Para usar favicon

Agrega en `<head>` del `index.html`:
```html
<link rel="icon" href="assets/favicon.ico" />
```
