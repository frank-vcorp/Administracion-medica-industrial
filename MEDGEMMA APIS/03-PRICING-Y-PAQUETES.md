# Pricing y Paquetes Probables

- ID: ARCH-20260513-03-PRICING
- Moneda base: MXN
- Referencia de costo IA: Featherless Premium 25 USD/mes para MedGemma 27B, no usado como base única de venta

## Principio de pricing

El servicio no debe venderse por costo del modelo, sino por valor operativo y clínico generado:

1. ahorro de tiempo médico
2. reducción de lectura manual repetitiva
3. consolidación multiestudio
4. estandarización operativa
5. capacidad de atender más casos con el mismo equipo

## Supuestos de justificación

1. una clínica paga por resolver flujo y tiempo, no por tokens
2. el costo del modelo es pequeño frente al valor de una implementación verticalizada
3. se justifica setup inicial por calibración, onboarding y activación

## Estructura recomendada

### 1. Setup inicial

Cobro único para:

1. configuración de tenant
2. branding básico
3. calibración inicial por estudios contratados
4. onboarding y capacitación

### 2. Suscripción mensual

Cobro recurrente para:

1. acceso a la plataforma
2. uso del copiloto clínico
3. soporte operativo
4. mantenimiento evolutivo menor

### 3. Adicionales

1. más sucursales
2. más tipos de estudio
3. white-label
4. integración API o con sistema tercero

## Paquetes sugeridos

### Piloto Demo

Precio sugerido:

1. setup: 6,900 MXN
2. mensualidad: 3,900 MXN

Incluye:

1. 1 clínica o unidad
2. 2 tipos de estudio
3. demo funcional
4. carga multiarchivo básica
5. consolidado multiestudio
6. soporte de arranque

Justificación:

1. baja barrera de entrada
2. ideal para validar antes de contrato mayor
3. te permite cerrar ventas rápidas sin regalar implementación

### Starter Clínica

Precio sugerido:

1. setup: 14,900 MXN
2. mensualidad: 8,900 MXN

Incluye:

1. 1 sucursal
2. hasta 4 tipos de estudio
3. branding ligero
4. consolidado multiestudio
5. panel básico de casos
6. soporte por WhatsApp y correo

Justificación:

1. ya resuelve un caso real de operación clínica
2. sigue siendo accesible para clínica pequeña o mediana

### Pro Multisucursal

Precio sugerido:

1. setup: 29,900 MXN
2. mensualidad: 18,900 MXN

Incluye:

1. hasta 3 sucursales
2. hasta 6 tipos de estudio
3. consolidado multiestudio avanzado
4. más usuarios internos
5. soporte prioritario
6. reportes operativos básicos

Justificación:

1. agrega verdadero valor administrativo y clínico
2. apunta a clínicas con mayor volumen y necesidad de estandarización

### Enterprise / White Label

Precio sugerido:

1. setup: desde 79,900 MXN
2. mensualidad: desde 39,900 MXN

Incluye:

1. white-label
2. multi-sucursal ampliado
3. integración con sistemas terceros
4. dominio o subdominio dedicado
5. soporte y acompañamiento de implementación

Justificación:

1. el cliente paga por velocidad, personalización y control
2. abre puerta a grupos clínicos o integradores B2B

## Modalidad alternativa por caso o por estudio

Puede ofrecerse de forma complementaria, no como oferta principal.

Ejemplo:

1. lectura individual por estudio desde 39 a 99 MXN por archivo, dependiendo del tipo
2. consolidado multiestudio por caso desde 149 a 299 MXN

Uso recomendado:

1. pruebas iniciales
2. clientes con volumen muy incierto
3. partner channels

## Reglas comerciales recomendadas

1. nunca regalar setup si habrá calibración o personalización real
2. sí puedes bonificar parte del setup al cerrar anualidad
3. el piloto debe convertirse a Starter o Pro si el cliente valida valor

## Estrategia de presentación comercial

Presentar siempre en este orden:

1. problema
2. ahorro operativo
3. demo
4. pricing

No presentar primero costo del modelo ni del proveedor.

## Frase de venta recomendada

No cobramos por usar una IA. Cobramos por darte una herramienta clínica ocupacional lista para leer estudios, estructurar hallazgos y apoyar al médico con consolidado multiestudio.
