# Casos de Uso y Modalidades de Implementación

- ID: ARCH-20260513-03-USECASES

## Casos de uso prioritarios

### 1. Clínica ocupacional

Uso:

1. subir estudios del trabajador
2. leer cada estudio con apoyo IA
3. consolidar criterio clínico preliminar

Valor:

1. más velocidad de lectura
2. mejor estandarización
3. menor dispersión entre estudios

### 2. Laboratorio con interpretación asistida

Uso:

1. agregar capa de lectura clínica a estudios entregados por el laboratorio
2. acompañar reportes internos o revisión médica

Valor:

1. mayor diferenciación comercial
2. posibilidad de vender servicio premium

### 3. Campañas médicas industriales

Uso:

1. procesar lotes de estudios por jornada
2. obtener lectura individual y consolidada por trabajador

Valor:

1. throughput operativo
2. trazabilidad por caso

### 4. API B2B para integradores

Uso:

1. software médico tercero consume tu servicio vía API
2. tú provees extracción y consolidado clínico como backend especializado

Valor:

1. ingresos recurrentes B2B
2. menos dependencia de venta directa a clínica final

### 5. White-label para grupos clínicos

Uso:

1. misma tecnología con marca del cliente
2. operación bajo su dominio o su panel

Valor:

1. ticket alto
2. barrera competitiva superior

## Modalidades de implementación

### A. Demo standalone

Objetivo:

1. mostrar valor rápido
2. cerrar ventas

Componentes:

1. upload
2. prediagnóstico por estudio
3. consolidado final

### B. Módulo embebido en producto existente

Objetivo:

1. usar el flujo del repo actual
2. exponer la funcionalidad como módulo interno

### C. Producto comercial separado

Objetivo:

1. venderlo ya como servicio autónomo
2. desacoplar comercialmente del sistema AMI principal

### D. Servicio semimanual asistido

Objetivo:

1. operación inicial con supervisión humana alta
2. útil para clientes premium o pilotos de validación clínica

## Casos de combinación multiestudio más valiosos

1. Examen Médico + Audiometría
2. Examen Médico + Espirometría
3. Examen Médico + Laboratorio
4. Audiometría + Espirometría + Laboratorio
5. paquete de ingreso ocupacional completo

## Propuesta de venta por vertical

Mensaje:
