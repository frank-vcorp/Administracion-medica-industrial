# MEDGEMMA APIS

Paquete documental comercial, técnico y de producto para vender un servicio verticalizado basado en extracción multimodal con Gemini 2.5 y razonamiento clínico con MedGemma.

Este paquete vive separado del producto principal para permitir:

1. preparar una oferta comercial inmediata
2. definir el demo mínimo vendible
3. documentar la implementación técnica y operativa
4. escalar a otras clínicas, laboratorios y clientes B2B

## Decision central del producto

1. Gemini 2.5 se usa para lectura documental, OCR y extracción multimodal
2. MedGemma se usa para prediagnóstico asistido por estudio y consolidado multiestudio
3. el sistema nunca reemplaza la decisión final del médico
4. el producto vendible es el servicio y la plataforma, no la reventa bruta del modelo
