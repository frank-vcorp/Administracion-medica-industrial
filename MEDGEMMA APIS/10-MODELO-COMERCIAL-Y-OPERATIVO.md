# Modelo Comercial y Operativo

- ID: ARCH-20260513-06
- Objetivo: definir como se vende, como se contrata y como se activa el servicio cuando un cliente real quiere avanzar

## Tesis comercial

No estamos vendiendo acceso a un modelo.

Estamos vendiendo una solucion operativa para salud ocupacional que:

1. lee estudios
2. estructura parametros clinicos
3. genera prediagnostico por estudio
4. consolida multiples estudios del mismo caso
5. acelera el trabajo del equipo medico sin sustituirlo

## Que se vende realmente

La oferta debe empaquetarse como servicio, no como tecnologia aislada.

### Oferta base

1. implementacion inicial
2. calibracion de estudios priorizados
3. acceso al micrositio, demo o plataforma
4. soporte operativo
5. evolucion menor segun paquete

### Formas de venta validas

1. piloto demo
2. suscripcion mensual por clinica o sucursal
3. white-label
4. API B2B para integradores

## Que contratariamos cuando el cliente diga que si

La contratacion no debe arrancar con un contrato enorme si el cliente aun esta validando valor. Debe existir una ruta simple por etapas.

### Ruta recomendada de cierre

#### Etapa 1. Piloto pagado

Ideal para:

1. clinicas pequenas o medianas
2. laboratorios que quieren validar rapido
3. prospectos que aun no quieren compromiso largo

Se cobra:

1. setup inicial
2. mensualidad del piloto

Se firma:

1. propuesta comercial o cotizacion aceptada
2. orden de servicio simple o carta de aceptacion
3. acuerdo de confidencialidad si compartiran muestras reales

#### Etapa 2. Servicio recurrente

Ideal para:

1. clientes que ya validaron el piloto
2. cuentas que necesitan continuidad operativa

Se cobra:

1. setup si aun no se habia cobrado completo
2. mensualidad Starter o Pro
3. extras por sucursal, estudios o integraciones

Se firma:

1. contrato de servicio
2. anexo de alcance
3. anexo de niveles de servicio si aplica
4. anexo de privacidad o tratamiento de datos si el cliente lo exige

#### Etapa 3. White-label o API B2B

Ideal para:

1. integradores
2. grupos clinicos
3. laboratorios con marca propia

Se cobra:

1. setup enterprise
2. mensualidad enterprise
3. fees de personalizacion o integracion

Se firma:

1. contrato marco
2. anexo tecnico
3. anexo comercial
4. anexo de marca o white-label

## Que documentos debemos generar cuando entra un lead serio

Cuando un prospecto pase de curioso a potencial comprador, debemos producir un paquete de cierre minimo.

### Paquete minimo de cierre

1. propuesta comercial
2. cotizacion
3. alcance del piloto o del paquete contratado
4. lista de estudios incluidos
5. tiempos de activacion
6. responsable del cliente
7. responsable interno

### Paquete minimo de arranque

1. checklist de onboarding
2. lista de accesos o usuarios
3. muestras reales o casos de calibracion
4. criterios de exito del piloto
5. canal de soporte

## Flujo comercial recomendado

### 1. Entrada del lead

El lead entra por:

1. WhatsApp desde landing
2. referido
3. llamada directa
4. contacto por demo

### 2. Calificacion inicial

Las preguntas obligatorias son:

1. que tipo de organizacion eres
2. que estudios generan hoy
3. cuantos casos o estudios procesan al mes
4. quien revisa clinicamente hoy
5. buscan demo, piloto o implementacion formal

### 3. Discovery comercial corto

Objetivo:

1. entender el flujo real
2. escoger estudios de entrada
3. decidir si entra mejor a Piloto, Starter o Pro

Duracion sugerida:

1. 20 a 30 minutos

### 4. Demo

La demo debe mostrar solo valor visible:

1. carga de archivos
2. resultado por estudio
3. consolidado multiestudio
4. disclaimer de apoyo clinico

### 5. Propuesta y cotizacion

Despues de la demo se entrega una propuesta con:

1. paquete sugerido
2. setup
3. mensualidad
4. estudios incluidos
5. tiempo de activacion
6. supuestos y limites

### 6. Cierre

Cuando el cliente acepte:

1. se confirma paquete
2. se confirma persona responsable
3. se firma el documento adecuado segun etapa
4. se solicita anticipo o pago inicial

### 7. Activacion

Despues del pago o aceptacion formal:

1. se agenda onboarding
2. se reciben muestras reales
3. se configuran estudios contratados
4. se habilita el ambiente o demo operativo
5. se inicia medicion de exito

## Como generariamos el servicio en operacion real

El servicio debe construirse de forma modular y repetible.

### Entregable operativo por cliente

1. tenant o entorno del cliente
2. configuracion de estudios incluidos
3. branding ligero o white-label si aplica
4. CTA o canal de soporte activo
5. criterios de exito definidos

### Secuencia de activacion recomendada

1. crear cliente
2. definir paquete
3. definir estudios contratados
4. cargar calibracion base o muestras
5. validar demo con cliente
6. pasar a uso operativo controlado

## Producto minimo que si debemos ofrecer al inicio

La oferta inicial debe ser simple para cerrar mas rapido.

### Recomendacion principal

Vender primero una de estas dos rutas:

1. salud ocupacional clasica: Examen Medico + Audiometria
2. lectura clinica general: Examen Medico + Laboratorio

### Ruta tecnica del piloto

Para validar MedGemma y no abrir demasiado frente tecnico:

1. Audiometria
2. Espirometria

## Como decidir que paquete ofrecer

### Piloto Demo

Ofrecer cuando:

1. el cliente quiere ver valor rapido
2. aun no tiene presupuesto aprobado grande
3. quiere probar con 2 estudios primero

### Starter Clinica

Ofrecer cuando:

1. ya tiene flujo real repetitivo
2. tiene uno o dos medicos o coordinadores usando la herramienta
3. necesita al menos 3 o 4 estudios configurados

### Pro Multisucursal

Ofrecer cuando:

1. ya tiene mas de una sede
2. necesita estandarizacion operativa
3. quiere reportes y soporte prioritario

### Enterprise / White-label

Ofrecer cuando:

1. necesita marca propia
2. quiere API o integracion
3. es grupo clinico o integrador

## Riesgos comerciales a controlar

1. vender demasiado alcance en la primera llamada
2. prometer automatizacion clinica total
3. aceptar demasiados estudios desde el dia uno
4. no definir responsable clinico del lado del cliente
5. cerrar sin criterios de exito del piloto

## Script de cierre simple

Cuando un prospecto quiera avanzar, la respuesta operativa debe ser:

1. te propongo arrancar con un piloto pagado y medible
2. definimos 2 estudios de entrada y un flujo real de tu operacion
3. activamos en pocos dias un entorno demostrable
4. medimos utilidad clinica y ahorro operativo
5. si valida valor, convertimos a paquete recurrente

## Decision operativa recomendada hoy

1. vender el primer cierre como piloto pagado
2. usar cotizacion + orden de servicio simple como mecanismo inicial
3. dejar contrato marco solo para cuentas recurrentes o enterprise
4. convertir el piloto exitoso a Starter o Pro
