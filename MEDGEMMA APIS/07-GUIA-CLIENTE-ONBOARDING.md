# Guía de Cliente y Onboarding

- ID: ARCH-20260513-03-CLIENT
- Audiencia: clínica, laboratorio, comprador, coordinador médico

## Qué es este servicio

Copiloto Clínico Ocupacional es una plataforma de apoyo que ayuda a leer estudios médicos, estructurar datos clínicos y generar prediagnóstico asistido por estudio y de forma consolidada.

## Qué resuelve

1. acelera la lectura documental
2. organiza parámetros clínicos
3. consolida varios estudios del mismo caso
4. entrega apoyo al médico para revisión final

## Qué no hace

1. no reemplaza al médico
2. no emite dictamen final automático
3. no otorga aptitud laboral automática

## Cómo funciona para el cliente

1. sube uno o varios estudios
2. la plataforma lee y estructura la información
3. genera un prediagnóstico por estudio
4. genera un consolidado multiestudio cuando aplica
5. el médico revisa y decide

## Qué necesita el cliente para empezar

1. definir persona responsable del proyecto
2. definir tipos de estudio prioritarios
3. compartir muestras reales para calibración inicial
4. acordar flujo operativo y usuarios clave

## Entregables al cliente

1. acceso al demo o ambiente de trabajo
2. capacitación inicial
3. configuración de estudios priorizados
4. acompañamiento de arranque

## Tiempo estimado de activación

1. piloto demo: 3 a 7 días hábiles
2. starter: 1 a 3 semanas
3. pro o enterprise: según integración y personalización

## Indicadores de éxito sugeridos

1. reducción de tiempo de lectura por caso
2. porcentaje de estudios bien estructurados
3. utilidad percibida del prediagnóstico
4. uso del consolidado multiestudio por el equipo médico

## Recomendaciones para el cliente

1. empezar con 2 o 3 tipos de estudio
2. validar sobre casos reales del flujo operativo
3. usar el consolidado como apoyo, no como sustituto de criterio clínico
