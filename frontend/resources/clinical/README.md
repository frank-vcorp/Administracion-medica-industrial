# Catálogo clínico CIE-10 (español)

`cie-10-es.json` contiene códigos CIE-10 seleccionables (nivel ≥ 3) derivados del repositorio público [verasativa/CIE-10](https://github.com/verasativa/CIE-10) (`codes.json`), alineado con la clasificación internacional de enfermedades. No se inventan códigos en aplicación: la validación Zod exige pertenencia a este catálogo al cerrar la consulta médica.
