## Decisiones Técnicas

1. **AppShell como client component:** `usePathname()` y `useSession()` son hooks de cliente. La alternativa (route groups `(app)/(auth)`) implicaba mover todos los archivos de rutas — mayor riesgo sin beneficio adicional. El resultado visual es idéntico.

2. **Optimistic rendering durante carga de sesión:** Cuando `status === 'loading'`, se muestran los ítems de staff operativo (el middleware ya validó autenticación server-side). Esto evita un flash de sidebar vacío. Los ítems admin se ocultan hasta confirmar rol ADMIN — mínimo momento sin visibilidad de admin items.

3. **Botón Editar eliminado (no conectado a modal):** No existe flujo de edición de empresa implementado en la vista destino ni en server actions. Se optó por una sola CTA clara en lugar de abrir el modal `CompanyFormModal` (que es solo para crear). El link al detail page cubre configuración + puestos.

4. **`/dashboard` como aterrizaje:** La ruta `/dashboard` existe y compila. Es más representativa del sistema actual que `/workers`.

5. **Middleware intacto:** No se tocó `src/middleware.ts`. La seguridad sigue siendo servidor-first; el filtrado de sidebar es UX adicional, no reemplazo de protección.
