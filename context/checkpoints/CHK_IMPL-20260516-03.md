```ts
const data = {
  ...(initial ?? {}),         // preserva: fieldDefinitions, versions, aiAssistance, etc.
  enabled,
  canonicalStudyType: ...,
  extraction: {
    ...(extraction ?? {}),    // preserva campos de extracción no editados
    schemaVersion: extractPromptVersion.trim() || null,
  },
  diagnosis: {
    ...(diagnosis ?? {}),     // preserva campos de diagnóstico no editados
```

Configuraciones previas que tengan `targetFields` o `requiresDoctorCalibration` **siguen cargando sin romper** (los campos existen en el objeto en memoria) pero **no se re-persisten** si el usuario no los vuelve a poner. Comportamiento esperado según SPEC.
