## Detalle de cambios por archivo

### `backend/requirements.txt`
- Agregado `boto3` (trae `botocore` como dependencia transitiva)

### `backend/app/main.py`
1. **Import**: `from fastapi.responses import RedirectResponse`
2. **S3 config (globals)**: Lee 5 vars de entorno:
   - `STORAGE_S3_ENDPOINT`, `STORAGE_S3_REGION`, `STORAGE_S3_BUCKET`
   - `STORAGE_S3_ACCESS_KEY`, `STORAGE_S3_SECRET_KEY`
   - Inicializa `_s3_client` y `_s3_enabled=True` solo cuando todas están presentes
   - Falla silenciosamente con warning si boto3 no puede inicializarse
3. **Helper `_upload_file_to_s3(contents, key) → bool`**: sube bytes al bucket. No loguea secretos.
4. **`POST /api/v1/upload-only`**: 
   - Si S3 habilitado → sube al bucket y retorna `file_url: /api/files/<filename>`
   - Fallback → filesystem local y retorna `file_url: /uploads/<filename>`
5. **`POST /api/v2/studies/upload-and-analyze`**:
   - Siempre guarda en disco local (requerido para pipeline IA)
   - Si S3 habilitado → también sube al bucket
   - Agrega campo `file_url` en la respuesta (antes no existía)
6. **`GET /api/files/{key:path}`** (nuevo endpoint):
   - Genera URL presignada de 5 minutos en Railway Storage
   - Retorna HTTP 302 redirect → no expone presigned URL en logs ni DB
   - 503 si S3 no configurado, 500 si falla generación de URL

### `frontend/src/actions/ai-prediagnosis.actions.ts`
- Interfaz `StudyAIAnalysisResult`: nuevo campo opcional `fileUrl?: string`
- `triggerStudyAIAnalysis`: usa `result.file_url ?? /uploads/${result.file}` para:
  - `sourceFileUrl` en `StudyExtractionSnapshot`
  - `fileUrl` en `EventTest` (actualización DB)
  - Campo `fileUrl` retornado al caller

### `frontend/src/actions/event-test.actions.ts`
- En flujo V2 exitoso: `fileUrl: v2Result.fileUrl ?? /uploads/${file.name}`
  (antes era siempre `/uploads/${file.name}` ignorando la URL real del backend)

## Flujo resultante

```
1. Usuario sube archivo → uploadEventTestFile()
2. Backend upload-only / v2-upload:
   - Si STORAGE_S3_* configuradas → sube a Railway Bucket
   - Retorna file_url: /api/files/<key>
3. Frontend persiste fileUrl = /api/files/<key> en EventTest.fileUrl
4. Visor: apiUrl + /api/files/<key> → GET /api/files/<key>
5. Backend genera presigned URL (5 min) → HTTP 302 → archivo en bucket
6. regenerateStudyAI: apiBase + /api/files/<key> → mismo flow → descarga OK
```
