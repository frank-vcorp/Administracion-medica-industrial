- No se tocan snapshots previos ni datos de revisión médica.
- Se reutiliza `triggerStudyAIAnalysis` como punto único de verdad para el pipeline IA.

## Archivos Modificados

### 1. `frontend/src/actions/event-test.actions.ts`

**Adición:** `regenerateStudyAI(eventTestId, eventId, triggeredByUserId)`

Flujo:
1. Carga el `EventTest` desde Prisma para obtener `fileUrl` y verificar elegibilidad.
2. Descarga el archivo usando `fetch(NEXT_PUBLIC_API_URL + fileUrl)`.
3. Reconstruye `File` desde el `Blob` descargado.
4. Determina el tipo canónico con `getCanonicalAIStudyType`.
5. Arma `FormData` y llama a `triggerStudyAIAnalysis` (V2 inmutable).
6. Persiste `resultNotes` con `buildAIResultNote` (éxito o error).
7. Persiste error en `resultNotes` si el proceso falla antes de llegar a `triggerStudyAIAnalysis`.
8. Llama a `revalidatePath` en todos los caminos.

### 2. `frontend/src/components/clinical/PapeletaWorkspace.tsx`

**Cambios:**
- Import: agrega `regenerateStudyAI`
- Estado: `isRegenerating: boolean`, `regenError: string`
- Handler: `handleRegenerateAI(testId)` — llama a la action, refresca router
- Props de `StudyPanel`: agrega `isRegenerating`, `regenError`, `onRegenerateAI`
- **Tarjeta de recuperación** en `StudyPanel` (antes del panel IA existente):
  - Condición: `isAIEligible && !test.aiSnapshot && test.fileUrl`
  - Muestra: ícono ⚠️, explicación en texto, nombre del archivo vinculado
  - Botón "Generar IA ahora" (oculto en `readonly`, deshabilitado mientras `isRegenerating`)
  - Error inline si `regenError` tiene valor
