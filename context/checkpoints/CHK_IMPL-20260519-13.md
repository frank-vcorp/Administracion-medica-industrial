## Riesgos Residuales

| Riesgo | Severidad | Mitigación |
|--------|-----------|------------|
| `Qwen3-VL-30B` requiere imagen base64 válida; PDFs con texto vectorial pueden fallar en `get_b64_jpeg` si `pdf2image` no está disponible en runtime | Media | Captura de excepción en `call_featherless_vision`; `pdf2image`/`fitz` deben estar en `requirements.txt` |
| `FEATHERLESS_EXTRACTION_MODEL` no presente en `.env` del cliente → usa default `Qwen/Qwen3-VL-30B-A3B-Instruct` | Baja | El default está correcto; documentar en README y `.env.example` |
| `GEMINI_API_KEY` aún necesaria para inicializar `GeminiBase` en `PrediagnosticService` (aunque Gemini no se llame en producción cuando MedGemma activo) | Info | Por diseño — `GeminiBase.__init__` no valida la key al construir |
