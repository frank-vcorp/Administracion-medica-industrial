## Baseline conocido — bugs a evitar (lecciones de Atlas v1 y Manus v1)

### Atlas v1 (29/30) — NO repetir:
- **B7 roto:** JSON malformado → 500 en vez de 400 (falta try/catch en parse de JSON store al leer, o validación Zod del contenido persistido).
- No crea directorio `data/` → crash en checkout fresco (falta `mkdir -p` recursivo con `recursive: true`).
- Rutas async sin try/catch bajo Express 4 → unhandled rejection crashea el proceso.
- Cast `as Todo[]` sin validar datos persistidos → violación restricción 35.
- "Centralized error handler" como código muerto para rutas async (no captura rejections) → violación C2/C6.

### Manus v1 (27/30) — NO repetir:
- Race condition read-modify-write sin lock.
- `writeFile` directo sin tmp+rename → corrupción ante crash.
- PATCH ignora el body (no se puede des-completar).
- Errores swalloweados sin logging.
- Sin `ts-node-dev` en `package.json`.
